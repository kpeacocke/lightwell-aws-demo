# Contributing

Please open an issue or pull request describing the proposed change and its
motivation. Keep changes focused and include relevant validation results.

To validate the Maven scenarios, follow the prerequisites and run instructions
in [README.md](README.md). Use a scratch directory; the runner writes a new
timestamped evidence directory for each run. Review logs before sharing them.

The files in `source/` and `config/lightwell-settings.xml` include material
copied or adapted from upstream. Its licensing is not yet confirmed; do not
assume this project's MIT license grants rights to it. Preserve the source
manifest and provenance when changing the demo.

Submit only contributions you have the right to make under the project's
[license](LICENSE). See the license scope in [README.md](README.md).
